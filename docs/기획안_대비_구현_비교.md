## 4. 이번에 바꾼 것 (이 요청)

- 물주기 10번/밭 (−3%씩), 튜토리얼 3장 체험도 같은 규칙으로
- 위성(15단계 이상) 새 디자인: 금박 몸체, 격자 태양광 날개, 접시 안테나, 신호
- 작물 성장 화면 작물이 살랑살랑(밭마다 박자가 다르고 최대 약 3도)
- 농장 화면 하늘과 그림 사이 띠 제거(이음새를 구름·부드러운 전환으로)
- 레벨업 카드를 벡터로 새로 그림(확대해도 선명)
- 특별 상점: 가격 인하(희귀 씨앗 100→60, 농장 장식 80→50, 특별 보관함 200→120, 행운의 비료 150→90), 새 상품 5개(물방울 꾸러미·번개 촉진제·씨앗 선물 상자·금화 주머니·농부 교본), 판매 1건당 Point 5→10
- 씨앗 꾸러미: 작물이 21종이 되며 값이 186,584P까지 뛴 버그를 기본 6종 기준으로 되돌림
- 수확·파종 알림에 이모지 대신 작물 그림
- 판매 / 뉴스("전국 농부 뉴스") / 시세 상세("시세판 상세": 7·14·30일 면적 그래프, 거래량·평균가, 시세 알림) 화면을 시안에 맞춤
- 서버 `tools/update_prices.mjs`: `KEEP_DAYS` 14 → 30 (다음 Actions 실행 때 지난 16일치를 한 번 더 받는다)

## 5. 확인이 필요한 것 (코드만으로는 알 수 없음)

1. **고객센터 문의**: 앱은 `feedback` 컬렉션에 쓰는데, 저장소의 `firestore.rules`에는 `feedback` 규칙이 없다(README 규칙에는 있음). 콘솔에 올라간 규칙이 어느 쪽인지 확인해야 한다. 없으면 문의 보내기가 permission-denied가 난다.
2. 수확 로컬 알림·FCM 수신: 실기기 확인(README 체크리스트에서도 미완).
3. APK 빌드·App Distribution 배포(10/16 목표).
4. 새 시세 알림은 시세 기록이 서버에서 30일치로 채워진 뒤에 30일 그래프가 가득 찬다.

## 6. 두 번째 수정 (에뮬레이터 확인 후)

- 시세 API **초당 요청 제한(429)** 대응: 앱은 요청을 한 줄로 세워 0.35초 간격으로 보내고 429면 다시 시도, 서버 스크립트도 간격을 둠. (작물 21종을 동시에 요청해서 그래프·거래량이 비던 원인)
- 서버: 나중에 추가된 작물은 지난 날짜 기록이 없던 문제 → 없는 작물만 다시 받아 채움 (`none` 표시로 중복 호출 방지)
- 하루의 기준을 **한국 시간(KST)** 으로 통일 (`dayTag`·`weekTag`), 시세 그래프 날짜도 한국 날짜
- 칭호: 눌러서 얻은 칭호 중 장착, 농장 화면 이름 옆에 표시, 진행률은 "다음 새 칭호까지"
- 수확 경험치 +60 → +100, 매칭 노란 힌트는 첫 한 쌍만(쉬움), 뉴스 카드 눌러서 이동, 미션 "전체 받기"가 위에도 있음
- 하우스 위성·신호·작물이 움직이고 농장 작물 흔들림이 더 크게, 농장 하늘 이음새(윗부분 10% 잘라 내고 숲 가장자리로 마무리), 농작물 통계 창 넘침 수정
- 레벨업 카드: 소·긴 머리 추가, 색종이는 코드로 그려 글자 뒤로
