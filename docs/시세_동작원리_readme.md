# 시세 농부 — "시세는 어떻게 실시간으로 움직일까?" 쉬운 설명서

> 튜토리얼에 나오는 **"농산물 가격은 실시간으로 변동됩니다."** 가 실제로 어떻게 돌아가는지 설명합니다.
> 관련 코드는 `lib/` 아래 파일 이름을 같이 적어 두었으니, 궁금하면 바로 열어 볼 수 있어요.

---

## 0. 한 줄 요약

> **진짜 도매시장 경매 기록(공공데이터 API)을 가져와서 → kg당 가격으로 바꾸고 → 거래량으로 평균을 내서 → 시세판에 보여줍니다.**
> 그 시세가 곧 게임에서 작물을 팔 때 받는 돈입니다.

"실시간"은 증권사 앱처럼 1초 단위가 아니라, **경매가 새로 올라오는 대로 약 10분 간격으로 따라가는 준실시간**입니다.

---

## 1. 전체 그림

```
 ┌──────────────────────────┐
 │ 공공데이터포털 API        │  ← 서울가락도매시장 "실시간 경매정보"
 │ (한국농수산식품유통공사)   │     (경매가 끝날 때마다 기록이 쌓임)
 └────────────┬─────────────┘
              │  10분마다
              ▼
 ┌──────────────────────────┐
 │ GitHub Actions (서버 역할)│  tools/update_prices.mjs
 │ 받아서 kg당 가격으로 계산  │  .github/workflows/prices.yml
 └────────────┬─────────────┘
              │  저장
              ▼
 ┌──────────────────────────┐
 │ Firestore  market/prices │  ← 모든 사용자가 같은 시세를 봄
 └────────────┬─────────────┘
              │  실시간으로 "듣는 중" (snapshots)
              ▼
 ┌──────────────────────────┐
 │ 앱 (시세판·튜토리얼·판매) │  lib/viewmodels/view_models.dart
 └──────────────────────────┘
```

서버(GitHub Actions)가 시세를 받아 Firestore에 저장해 두면, 앱은 그 문서를 **계속 듣고 있다가** 값이 바뀌는 순간 화면을 바로 바꿉니다.
그래서 사용자 수가 늘어도 공공 API를 사용자마다 부르지 않아요. (공공 API는 하루 호출 한도가 있어서 아낍니다.)

## 3. 시세는 어떻게 계산하나요?

### 3-1. kg당 가격으로 맞추기
경매 건마다 포장 크기가 달라서(10kg, 15kg, 20kg…) 그대로 비교할 수 없어요. 그래서 전부 **kg당 가격**으로 바꿉니다.

```
kg당 가격 = 낙찰가 ÷ 단위 물량(kg)       예) 10,000원 ÷ 10kg = 1,000원/kg
거래량(kg) = 포장 개수 × 단위 물량         예) 50상자 × 10kg   = 500kg
```

- 단위가 g, 톤이면 kg로 환산합니다.
- 단위가 "개, 속, 단"처럼 **무게를 알 수 없으면 계산에서 뺍니다.**

### 3-2. 거래량 가중평균
그날의 경매 건이 수백~수천 건이므로 단순 평균 대신 **많이 거래된 가격에 더 큰 비중**을 줍니다.

```
시세 = Σ(kg당 가격 × 거래량) ÷ Σ(거래량)
```

예) 1,000원/kg × 500kg, 1,200원/kg × 100kg 이면
`(1000×500 + 1200×100) ÷ 600 = 1,033원/kg` (코드: `lib/core/game_rules.dart`의 `weightedPrice`)

### 3-3. 경매 건 우선
`trd_se`가 **"경매"** 인 건만 쓰고, 그날 경매 건이 하나도 없을 때만 정가·수의 거래까지 포함합니다. (시세판 기준과 같게 맞추기 위해서)

### 3-4. 등락률 (▲ +11.7% 같은 표시)
```
등락률(%) = (오늘 시세 − 직전 거래일 시세) ÷ 직전 거래일 시세 × 100
```
- 오르면 **빨강 ▲**, 내리면 **파랑 ▼** (한국 시세 표기 방식)
- 0.0%면 오르지도 내리지도 않은 **보합 –**
- 코드: `lib/core/progress_rules.dart`의 `changePercent`

## 4. 휴장일·데이터가 없을 때는?

- 일요일·명절처럼 **경매가 없는 날**은 최근 7일 안에서 거래가 있었던 **가장 최근 날**의 시세를 씁니다. 시세판에 "10월 7일 기준"처럼 기준 날짜가 같이 표시돼요.
- "전일 시세"도 휴장일을 건너뛰고 **그 전에 거래가 있었던 날**을 씁니다.
- API가 실패하면 **마지막으로 성공한 시세**(기기에 저장해 둠)로 계속 진행합니다.
- 서버 시세가 1시간 넘게 갱신되지 않으면 앱이 직접 API를 불러 보충합니다.

## 5. 앱은 언제 시세를 갱신하나요?

| 상황 | 동작 |
| --- | --- |
| 서버가 Firestore에 새 시세 저장 | 앱이 **즉시** 화면 갱신 (실시간 구독) |
| 서버 시세가 최신이면 | 앱은 API를 **직접 부르지 않음** (호출 한도 절약) |
| 서버 시세가 끊기면 | 앱이 **5분마다** 직접 조회 (10분 안에 다시 부르면 저장해 둔 값 사용) |
| 앱을 백그라운드에서 다시 켤 때 | 새로고침 |
| 시세판 새로고침 버튼·당겨서 새로고침 | 즉시 새로고침 |
| API 키가 없는 개발 환경 | 샘플 시세(실제 경매 스냅샷 + 가짜 변동값)로 동작 |

핵심 코드: `MarketViewModel` (`lib/viewmodels/view_models.dart`), `MarketRepository` (`lib/repositories/market_repository.dart`)

## 6. 서버(GitHub Actions)는 무엇을 하나요?

`tools/update_prices.mjs`가 10분마다 실행됩니다.

1. 최근 14일 × 작물 6종의 경매 건을 API에서 받아요. (1,000건씩 여러 쪽)
2. 3장의 계산으로 하루치 `{ p: kg당 가중평균가, v: 거래량(kg) }`를 만들어요.
3. 오늘·어제는 거래가 계속 들어오므로 매번 다시 받고, **그 전 날짜는 한 번 받으면 재사용**해요.
4. 가장 최근 거래일과 그 전 거래일을 골라 시세판용 값을 만들어요.
5. Firestore `market/prices` 문서에 저장해요.

저장 모양:

```
market/prices
 ├─ updatedAt : 저장 시각
 ├─ CABBAGE   : { price, prev, asOf: "2026-10-07", prevDate, volumeKg }
 ├─ RADISH    : { ... }  (작물마다)
 └─ days      : { "2026-10-07": { CABBAGE: { p, v }, ... }, ... }   ← 7일 그래프용
```

## 7. 이 시세가 게임에서 어떻게 쓰이나요?

```
판매 금액 = 수확량(kg) × 판매하는 순간의 kg당 시세 × 신선도
```

- **신선도**: 창고에 하루 보관할 때마다 5%씩 떨어지고, 최저 70%까지만 내려가요. (`freshnessOf`)
- 판매 순간의 시세와 기준 날짜가 **거래 기록**에 같이 남아요.
- 같은 작물이라도 **언제 파느냐에 따라 수익이 달라지는 것**이 이 게임의 핵심입니다.
- 시세를 불러오지 못한 상태에서는 판매하지 않아요.

## 9. 날씨 정보는? (함께 물어보신 부분)

농장 화면의 "오늘의 날씨"도 실제 API입니다. (`lib/services/weather_service.dart`)

1. `OPENWEATHER_API_KEY`가 있으면 **OpenWeather**(현재 날씨)를 먼저 사용
2. 키가 없거나 실패하면 **Open-Meteo**(무료·키 없음)로 자동 전환
3. 둘 다 실패하면 "날씨를 불러오지 못했어요"
4. 기준 위치는 서울(37.5665, 126.9780)이고 **30분마다** 다시 불러와요.

## 10. 자주 하는 질문

**Q. 왜 시세가 한참 안 바뀌어 보이나요?**
경매는 장이 열리는 시간에만 새 기록이 쌓여요. 새벽·장 마감 후·일요일에는 직전 거래일 시세가 그대로 보이는 게 정상입니다.

**Q. 가락시장 가격이 우리 동네 마트 가격과 달라요.**
도매시장 경매 낙찰가이므로 소매가보다 낮아요. 그래서 "가상 게임이며 실제 투자·거래 조언이 아닙니다"를 화면에 표시합니다.

**Q. 시세판의 "○월 ○일 기준"은 무슨 뜻이에요?**
그 시세를 계산한 거래일입니다. 오늘 경매가 없으면 가장 최근 거래일이 표시돼요.

**Q. API 키가 없으면 어떻게 되나요?**
샘플 시세로 동작합니다(개발·테스트용). 서버가 저장해 둔 Firestore 시세가 있으면 앱은 키가 없어도 그 **실제 시세**를 우선 사용해요.
